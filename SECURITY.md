# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Principles of Security in LOAM Launcher

LOAM is designed with strict desktop security principles:
1. **Zero Credential Sharing**: LOAM never sees your Microsoft password. Authentication uses the official system browser with PKCE (Proof Key for Code Exchange) loopback redirect.
2. **Encrypted Token Vault**: Tokens are stored exclusively in the Windows Credential Manager backed by DPAPI (Data Protection API).
3. **No Credential Ingestion**: LOAM does not read, import, or store credentials from other third-party launchers (e.g., TLauncher). The "Import from another launcher" feature imports game data only (`saves`, `mods`, `resourcepacks`, `shaderpacks`, `options.txt`, `servers.dat`).
4. **Automatic Redaction**: Logs, launch plans, and diagnostic bundles generated by LOAM automatically redact Microsoft tokens, refresh tokens, Xbox user hashes, emails, and local Windows user paths before export.
5. **No Telemetry / No Silent Background Uploads**: LOAM does not transmit telemetry or user activity. All diagnostic exports are strictly user-initiated.

## Reporting a Vulnerability

If you discover a security vulnerability within LOAM Launcher:
- **Do NOT create a public GitHub issue** or post details in public Discord channels.
- Please email security disclosures to `security@loamlauncher.org` (or open a Private Vulnerability Advisory on GitHub at `https://github.com/whynotdhyan/loam-launcher/security/advisories/new`).
- Provide a detailed description, reproduction steps, and potential impact.
- We will acknowledge receipt within 48 hours and work with you on a coordinated disclosure timeline.
